# Changelog

All notable changes to OreoLeads are documented in this file.

## [1.0.0] - 2026-07-17

### Added

- **Lead Management** -- Full CRM with leads, notes, follow-ups, activities, pipeline
- **AI Integration** -- AI-powered email draft generation and website analysis
- **Brevo Integration** -- Transactional email delivery engine with webhooks, queues, stats
- **Airtable Integration** -- Bidirectional sync with conflict resolution and versioned encryption
- **Automation Engine** -- No-code workflow builder with 25+ triggers/actions, scheduler, queue
- **Executive Analytics** -- KPI dashboard, sales funnel, email analytics, forecasting, reporting
- **Multi-tenant** -- Full organization isolation via OrganizationId
- **Security** -- AES-256-GCM encryption, JWT, RBAC, audit log, security headers, rate limiting
- **Production-ready** -- Docker, CI/CD, health checks, observability, structured logging

### Technical

- ASP.NET Core 10 with Clean Architecture
- React 19 + TypeScript + TanStack Query + Recharts
- PostgreSQL 17 with EF Core 10 and automatic migrations
- 342 tests (unit + integration)
